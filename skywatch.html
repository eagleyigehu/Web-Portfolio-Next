SkyWatch

A Web GIS interface exploring how migration maps, habitat questions and public sightings could support a conversation about floating habitats for the Chinese Crested Tern.

Explore the interactive demo ↗
Purpose
Make ecological information explorable and demonstrate an observation-entry workflow.
Design scope
Web map interface, visual layers, scenario controls and a session-only sighting form.
Status
Interactive prototype. Sample data and illustrative scores; not a deployed conservation system.

What you can explore

Navigate the map, switch demonstration layers, explore migration routes, adjust model weights and try entering a sighting.

The project combines a visual language drawn from illustration with an interface for exploring ecological questions.

What remains to be developed

Verified source datasets, a validated habitat model, persistent observation storage and review by relevant domain specialists.

Entries reset when the page reloads. Changing weights updates an illustrative score, not a geographic site recommendation.
